# Minecraft Addons

このフォルダは、Minecraft Bedrock Edition向けアドオンをまとめて保存する場所です。

## フォルダ構成

アドオンごとにフォルダを作成し、ビヘイビアーパック（BP）やリソースパック（RP）、説明ファイルなどを整理して配置してください。

例：

```text
Addons/
└── ExampleAddon/
    ├── BP/
    ├── RP/
    └── README.md
```

## 対象

- Minecraft Bedrock Edition
- ビヘイビアーパック（BP）
- リソースパック（RP）
- `.mcaddon` / `.mcpack` 形式のアドオン
